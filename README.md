# sendinggmail

一個批次寄送 Gmail 郵件的小工具。使用者將 Excel 檔案匯入軟體後，軟體會自動寄信給檔案中列出的每一個收件人信箱。

## 功能規劃

- **匯入 Excel**：使用者上傳 / 拖曳 Excel 檔案，軟體讀取檔案中的收件人信箱清單
- **批次寄信**：自動寄信給 Excel 檔案裡的每一個信箱
- **客製化內容**：使用者可選擇是否要客製化每封信的內容（例如依 Excel 欄位資料個人化信件）
- **收件人類型**：寄信時可選擇收件人要放在「收件人（一般）」、「副本（CC）」或「密件副本（BCC）」
- **排程寄信**：可設定安排的寄信時間，讓軟體在指定時間自動寄出
- **批次數量控制**：可設定每次寄送要一次寄給多少人（分批寄送）

## 技術方案

- 介面：Streamlit 網頁介面（本機執行，用瀏覽器操作）
- 寄信方式：Gmail API（OAuth 授權）
- 程式語言：Python

## 快速開始（終端機指令）

以下指令都在專案資料夾內執行（`cd` 進 `sendinggmail` 之後）：

```bash
# 1. 建立虛擬環境（只需要做一次）
python3 -m venv .venv

# 2. 啟用虛擬環境（每次開新的終端機視窗都要重做這步）
source .venv/bin/activate

# 3. 安裝套件（只需要做一次，之後 requirements.txt 有更新才需要重跑）
pip install -r requirements.txt

# 4. 啟動軟體
streamlit run app.py
```

執行完第 4 步後，終端機會顯示一個網址（預設 `http://localhost:8501`），並自動幫你開啟瀏覽器；
如果沒有自動開啟，手動複製那個網址貼到瀏覽器打開即可。

> 之後每次要使用軟體，只需要重做「2. 啟用虛擬環境」跟「4. 啟動軟體」這兩步就好，
> 不用每次都重新建立虛擬環境或重新安裝套件。

## 第一次使用前：設定 Gmail API 授權

軟體是透過 Gmail API 幫你寄信，**每一個要用這個軟體寄信的人，都要用自己的 Google 帳號申請一組專屬的授權憑證**（不能共用別人申請好的檔案）。這一步只需要做一次，跟著下面的步驟做，不需要懂技術背景，全程都在 Google 的網頁上點滑鼠完成。

### 1. 建立 Google Cloud 專案

1. 瀏覽器打開 [console.cloud.google.com/projectcreate](https://console.cloud.google.com/projectcreate)
2. 用你要拿來寄信的那個 Google 帳號登入
3. 「專案名稱」隨便打一個，例如 `sendinggmail`
4. 按「建立」，等幾秒鐘讓專案建立完成

### 2. 啟用 Gmail API

1. 打開 [console.cloud.google.com/apis/library/gmail.googleapis.com](https://console.cloud.google.com/apis/library/gmail.googleapis.com)
2. 確認畫面最上方選的專案是剛剛建立的那個（不是的話點上方切換）
3. 按藍色的「**啟用**」按鈕，等它跑完

### 3. 設定 OAuth 同意畫面

1. 打開 [console.cloud.google.com/apis/credentials/consent](https://console.cloud.google.com/apis/credentials/consent)
2. 使用者類型選 **外部（External）**，按「建立」
3. 「應用程式名稱」隨便打，例如 `批次寄信工具`；「使用者支援電子郵件」「開發人員聯絡資訊」都填自己的 Gmail
4. 一路按「儲存並繼續」到「測試使用者」那一頁，按「新增使用者」，**把自己的 Gmail 加進去**
   - 這一步很重要：因為應用程式還沒經過 Google 正式審核，只有加進「測試使用者」名單的帳號才能登入使用
5. 儲存完成即可（不需要送審）

### 4. 建立 OAuth 用戶端 ID

1. 打開 [console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials)
2. 點「建立憑證」→「OAuth 用戶端 ID」
3. 應用程式類型選 **電腦版應用程式（Desktop app）**，名稱隨便打，按「建立」
4. 建立完成會跳出視窗，按「下載 JSON」

### 5. 放到專案資料夾

1. 把剛剛下載的 JSON 檔案改名為 `credentials.json`
2. 移到這個專案資料夾裡（跟 `app.py` 同一層）
3. ⚠️ 這個檔案**絕對不要**上傳到 GitHub 或分享給別人，等於是你的帳號金鑰（`.gitignore` 已經幫你排除，正常操作不會不小心推上去）

### 6. 登入使用

完成以上設定後，照下面「操作手冊」第 1 步「登入 Google 帳號」即可。第一次登入時 Google 可能會顯示「這個應用程式未經 Google 驗證」的警告畫面，這是正常的（因為還沒送審），點「**進階**」→「**前往〈應用程式名稱〉(不安全)**」繼續，同意授權即可。

## 操作手冊

啟動軟體（`streamlit run app.py`）、瀏覽器打開網頁後，依序操作：

1. **登入 Google 帳號**：點左側「登入 Google 帳號」，第一次會跳出瀏覽器頁面要你同意授權，
   用你要拿來寄信的那個 Google 帳號登入、同意即可。登入成功後左側會顯示你的信箱，
   之後開啟軟體都會記住這次授權，不用每次重登入。
2. **上傳 Excel 名單**：在「1. 上傳 Excel 收件人名單」上傳你的 `.xlsx` / `.xls` 檔案，
   畫面會預覽前 20 筆資料，接著從下拉選單選出「哪一欄是收件人信箱」。
3. **撰寫信件內容**：在「2. 撰寫信件內容」填「主旨」跟「內文」。
   - 如果想要每封信內容依 Excel 資料不同（例如帶入姓名），勾選「客製化寄信」，
     並在主旨/內文用 `{{欄位名稱}}` 帶入該筆資料，例如 `{{姓名}} 您好`。
   - 不勾選的話，所有人收到的內容都一樣。
4. **設定收件人類型與批次**：在「3. 收件人類型與寄送批次」選擇這批信要用
   「收件人（一般）」、「副本（CC）」還是「密件副本（BCC）」，並設定一次寄送人數
   （例如設 20，代表每封信會一次放 20 位收件人；若有勾選客製化寄信，則固定每人一封）。
5. **設定寄送時間**：在「4. 寄送時間」選「立即寄送」或「排程寄送」，
   排程寄送要選未來的日期與時間。
6. **確認並寄送**：在「5. 確認並寄送」確認有效收件人數沒問題後，按下「🚀 寄送」。
   - 立即寄送：畫面會即時顯示進度條，完成後顯示成功/失敗人數。
   - 排程寄送：畫面顯示「已排程於 ×××× 自動寄送」，**必須讓執行 `streamlit run app.py`
     的終端機視窗持續開著**（不能關閉、不能讓電腦睡眠），時間到才會真正寄出。
